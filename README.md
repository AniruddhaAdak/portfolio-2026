# Portfolio 2026 - Aniruddha Adak

An ultra-modern animated portfolio built with Next.js, featuring stunning Framer Motion animations, gradient effects, and a dark theme with neon accents.

## ✨ Features

- 🎨 **Gradient Hero Section** - Eye-catching animated gradient text and floating elements
- 📊 **Animated Skill Bars** - Smooth progress animations showcasing technical expertise
- 🎯 **Project Cards with Modals** - Interactive project showcase with detailed modal views
- 📅 **Career Timeline** - Animated timeline displaying professional journey
- 📧 **Contact Form** - Fully validated contact form with React Hook Form
- 🌊 **Smooth Scroll Animations** - Engaging scroll-triggered animations throughout
- 📱 **Fully Responsive** - Mobile-first design with responsive navigation menu
- 🎭 **Dark Theme** - Modern dark theme with neon blue, purple, and pink accents
- 📈 **Progress Indicator** - Visual scroll progress indicator
- ⚡ **Performance Optimized** - Built with Next.js 14+ for optimal performance

## 🚀 Tech Stack

- **Framework**: Next.js 14+ with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Forms**: React Hook Form
- **UI**: Custom components with modern design

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🎯 Development

Open [http://localhost:3000](http://localhost:3000) to view the portfolio in development mode.

## 📝 Customization

Edit the component files in the `/components` directory to customize:
- **Hero.tsx** - Main hero section content
- **Skills.tsx** - Skills and expertise data
- **Projects.tsx** - Project information and details
- **Timeline.tsx** - Career timeline events
- **Contact.tsx** - Contact form and information
